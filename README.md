# Dormitory Booking System

Жатқаханаға мұқтаж студенттерге орын іздеу, өтінім беру және оның статусын бақылау үрдісін автоматтандыруға арналған веб-қосымша[cite: 1, 2]. Жүйе студенттер пен коменданттардың жұмысын жеңілдетеді[cite: 1, 2].

## Мақсаты
Студенттерді жатақхана орындарымен қамту және өтінімдерді өңдеу процесін толығымен цифрландыру[cite: 1, 2].

## Пайдаланушылар
* Студент[cite: 1, 2]
* Комендант[cite: 1, 2]

## Талаптар
1. Студент жүйеге тіркеліп, жеке кабинетке кіре алады[cite: 1, 2].
2. Студент бос орындар мен бөлмелер тізімін қарай алады[cite: 1, 2].
3. Студент орналасуға өтінім беріп, қажетті құжаттарды жүктей алады[cite: 1, 2].
4. Студент өтінімінің статусын қадағалай алады[cite: 1, 2].
5. Комендант келіп түскен өтінімдер тізімін көре алады[cite: 1, 2].
6. Комендант студенттің өтінімін растайды немесе кері қайтарады[cite: 1, 2].
7. Жүйе бос орындар санын автоматты түрде жаңартып отырады[cite: 1, 2].
